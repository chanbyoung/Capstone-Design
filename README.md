## 🚀 프로젝트 구인 웹 사이트

> **캡스톤 디자인**  
**개발기간: 2024.03 ~ 2024.07**

### 📌 프로젝트 소개

스터디 그룹이나 프로젝트팀을 간편하게 찾고 구성할 수 있게 도와주는 **온라인 플랫폼 서비스**입니다.

### 🛠 개발 배경 및 필요성

- 📚 많은 학생들이 스터디 그룹이나 프로젝트 팀 구성에 어려움을 겪고 있음
- 🌐 기존 플랫폼들은 있지만, 학생들이 접근하기에 한계가 있음

### 🎯 기대 효과

- 🤝 학습 커뮤니티 활성화 및 효율적인 학습 지원
- 💡 학생들 간의 원활한 소통과 협업으로 새로운 지식과 아이디어 획득

## 🔧 Technical Stacks

- **Web BackEnd** : `Java 17`, `Spring Boot 3.1`, `JPA`, `Query DSL`, `MySql`, `Redis`
- **Versioning** : `Git`, `Notion(API 명세서)`
